## 2026-08-13 - [MEDIUM] Sensitive Information Exposure in Input
**Vulnerability:** API key input was visible in plaintext, making it vulnerable to shoulder-surfing.
**Learning:** Sensitive inputs such as API keys and passwords should always use masking features like `secureTextEntry` in React Native.
**Prevention:** Ensure `secureTextEntry` is set for all `TextInput` components handling credentials or secrets.
## 2026-08-15 - [MEDIUM] API Key Exposure in Error Messages
**Vulnerability:** Axios error messages (like `e.message`) could expose the full request URL, inadvertently logging or displaying the API key query parameter.
**Learning:** Error message strings generated by HTTP clients may contain sensitive query parameters. These strings must be sanitized before being returned to UI components or external loggers.
**Prevention:** Scrub known sensitive keys (e.g., `key=...`) using regular expressions from raw error messages before throwing them up the stack.
